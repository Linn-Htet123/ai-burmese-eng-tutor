PRD Section 7 · The core mechanic. Runs identically every time. Cyan = learner speaks, green = May speaks, violet = write.

Why the say-it-back is the mechanism

  • • Hearing a better sentence changes nothing
  • • Saying it out loud lays down the retrieval path
  • • R-UL-5: prompt once if skipped, then continue
  • • Never prompt twice — fighting the learner costs more than the missed rep

The R-UL-8/9 quality firewall

  • • Improvised upgrades produce confident nonsense
  • • Authored pool is the safety net
  • • Pool-miss → generated + flagged
  • • Founder reviews flagged upgrades weekly (R-CA-5)
  • • Pool also enables cached TTS for scripted lines

Upgrade priority (Section 7.3)

  • • 1. Verb choice — highest yield ("did" → "ran")
  • • 2. Collocation ("make a decision")
  • • 3. Compression — shorter is often better
  • • 4. Hedging ("roughly", "off the top of my head")
  • • 5. Turn-holding fillers — teach in session 1 at every level
