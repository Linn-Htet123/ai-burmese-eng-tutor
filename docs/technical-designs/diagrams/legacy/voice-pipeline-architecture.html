Voice Pipeline & Audio Storage

Learner ↔ May real-time loop + session recording · designs 02 & 03 · D-035…D-040

Latency budget — R-TE-1 (<1s)

  • • VAD end-of-speech: 100–200ms
  • • Yangon → SG backend: 30–60ms
  • • Backend → Gemini (same region): 5–20ms
  • • Gemini think + first audio: 400–600ms
  • • Return + playback start: 40–80ms
  • • Total ~575–960ms — fits, little slack

Reliability — D-036

  • • Heartbeat: ping 20s, 2 missed pongs → reconnect
  • • Backoff 1s → 2s → 4s, cap 10s
  • • Resume by session ID; drop loses ≤10s (R-TE-6)
  • • Never resend prior audio (R-TE-5)
  • • Gemini down → text review session (R-TE-9)
  • • Crash loses 1 recording — accepted at MVP

Storage — D-039 / D-040

  • • Two tracks: learner-only clips stay cuttable (R-PR-2)
  • • M4A playback — old Safari/iOS safe
  • • Only learner + founder access (R-TE-10)
  • • Cohort 1 ≈ 12 GB ≈ $0.18/month
  • • Kept beyond course expiry — marketing asset
  • • Delete only on learner request
